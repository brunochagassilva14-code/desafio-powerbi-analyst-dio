# 📊 Criando um Relatório de Vendas Elegante com Power BI

## 📖 Introdução

Este projeto foi desenvolvido como parte do desafio **"Criando um Relatório de Vendas Elegante com Power BI"** da DIO.

O objetivo foi construir um relatório interativo utilizando a base de dados **Sample Financials**, aplicando conceitos de visualização de dados, navegação entre páginas, segmentação de informações e recursos de interatividade disponíveis no Power BI.

Durante o desenvolvimento foram utilizados elementos de design para tornar a experiência do usuário mais intuitiva, além de recursos como botões de navegação, segmentadores e indicadores para análise dos dados.

---

## 🎯 Objetivos do Projeto

- Desenvolver um relatório de vendas utilizando Power BI.
- Aplicar boas práticas de design e organização de dashboards.
- Criar navegação entre páginas através de botões.
- Utilizar segmentadores para filtros dinâmicos.
- Implementar indicadores para análise de desempenho.
- Explorar recursos de interatividade utilizando bookmarks.
- Consolidar conhecimentos em visualização de dados.

---

## 📊 Páginas Desenvolvidas

### Página 1

Dashboard principal contendo:

- Indicadores de vendas
- Indicadores de lucro
- Visuais comparativos
- Segmentadores de dados
- Navegação entre páginas

### Página 2

Relatório complementar contendo:

- Análises detalhadas de desempenho
- Comparativos entre categorias
- Visualizações adicionais dos indicadores
- Recursos de interatividade utilizando botões e bookmarks
